## بخش ۱ — چک‌لیست قوانین WordPress.org

| قانون | وضعیت تیکت‌چی لایت |
|---|---|
| لایسنس GPL یا سازگار | ✅ GPLv2 or later؛ فونت وزیرمتن OFL است که مجاز است |
| کد رمزگذاری‌شده یا مبهم ممنوع (ionCube و…) | ✅ حذف شد |
| امکانات قفل‌شده یا آزمایشی ممنوع (Trialware) | ✅ امکانات پرو داخل کد نیستند؛ فقط لینک تبلیغ هستند |
| محدودیت عددی (مثلاً «فقط ۳ دپارتمان») ممنوع | ✅ هیچ محدودیت عددی نداریم |
| درخواست به سرور خارجی یا ردیابی بدون اجازه کاربر ممنوع | ✅ هیچ درخواست خارجی‌ای نیست |
| تبلیغ مزاحم در کل پیشخوان ممنوع | ✅ تبلیغ فقط در صفحات خود افزونه است، به‌علاوه یک اعلان قابل‌بستن در پیشخوان |
| لینک «Powered by» در سایت کاربر بدون اجازه ممنوع | ✅ پنل مشتری هیچ لینک یا تبلیغی ندارد |
| پیشوند یکتا برای توابع و کلاس‌ها | ✅ `ticketchi_lite_` و `TicketchiLite\` |
| امن‌سازی ورودی و خروجی (sanitize/escape/nonce) | ✅ |
| فایل readme.txt استاندارد | ✅ |
| نام افزونه نباید با «WordPress» شروع شود یا برند دیگران را داشته باشد | ✅ Ticketchi Lite |

### نکاتی که ممکن است بازبین درباره‌شان سوال کند (جواب آماده)

1. **نام جدول‌ها و گزینه `tkm_`:** اگر گفتند پیشوند کوتاه است، جواب بده:
   > The `tkm_` database tables are shared with Ticketchi Pro so users can upgrade without losing tickets. All PHP functions, classes, constants, options and hooks of this plugin use the unique `ticketchi_lite` / `TicketchiLite` prefix.
2. **فارسی بودن متن‌های افزونه:** قانون اجباری نیست. اگر خواستند افزونه قابل‌ترجمه شود، بگو تا رشته‌ها را با `__()` و دامنه `ticketchi-lite` بسته‌بندی کنم.
3. **لینک‌های «PRO» در صفحات افزونه:** این‌ها فقط لینک به صفحه معرفی‌اند و کد مخفی پشتشان نیست. اگر گفتند زیاد است، تعدادشان را کم می‌کنیم؛ این مورد باعث رد نهایی نمی‌شود، فقط درخواست اصلاح می‌دهند.

## بخش ۲ — قبل از ارسال (۱۰ دقیقه)

1. **حساب کاربری بساز:** در https://login.wordpress.org/register ثبت‌نام کن. نام کاربری را با دقت انتخاب کن، چون در `readme.txt` و صفحه افزونه دیده می‌شود.
2. **ورود دومرحله‌ای (2FA) را فعال کن:** از Profile › Account & Security. برای نویسنده‌های افزونه لازم است.
3. **`readme.txt` را ویرایش کن:**
   - `Contributors: tahakarami` را با **نام کاربری خودت** عوض کن.
   - `Tested up to: 6.8` را با آخرین نسخه وردپرس (از wordpress.org/download) جایگزین کن.
4. **افزونه Plugin Check را تست کن:** روی یک سایت تستی افزونه رسمی **Plugin Check (PCP)** را نصب کن. بعد از ابزارها › Plugin Check، افزونه «Ticketchi Lite» را بررسی کن. همین ابزار هنگام ارسال هم خودکار اجرا می‌شود. اگر خطای قرمز (Error) داد، برایم بفرست تا درستش کنم. هشدارهای زرد (Warning) معمولاً مشکلی ایجاد نمی‌کنند.
5. **zip را بساز:** پوشه `ticketchi-lite` را zip کن، یا از همان فایل zipی که فرستادم استفاده کن.

## بخش ۳ — ارسال

1. برو به https://wordpress.org/plugins/developers/add/ و وارد شو.
2. فایل `ticketchi-lite.zip` را آپلود کن و تیک قوانین را بزن.
3. نامک (Slug) پیشنهادی `ticketchi-lite` است. **بعد از تأیید قابل تغییر نیست.**
4. یک ایمیل تأیید دریافت می‌کنی. بررسی معمولاً بین ۱ تا ۱۰ هفته طول می‌کشد، بسته به صف.
5. اگر بازبین ایمیل داد، **به همان ایمیل جواب بده** و zip اصلاح‌شده را آپلود کن (از همان صفحه add). اصلاحات را برایم بفرست تا انجامشان بدهم.

## بخش ۴ — بعد از تأیید: آپلود با SVN

بعد از تأیید، یک مخزن SVN به این آدرس می‌گیری:
`https://plugins.svn.wordpress.org/ticketchi-lite/`

**رمز SVN با رمز سایت فرق دارد:** از Profile › Account & Security › «SVN Password» یک رمز بساز.

### روی ویندوز (TortoiseSVN) یا با خط فرمان:

```bash
svn checkout https://plugins.svn.wordpress.org/ticketchi-lite ticketchi-svn
cd ticketchi-svn

# ۱) فایل‌های افزونه در trunk
cp -r /مسیر/ticketchi-lite/* trunk/

# ۲) بنر، آیکون و اسکرین‌شات‌ها در assets (نه داخل trunk)
cp /مسیر/wordpress-org-assets/*.png assets/

# ۳) نسخه منتشرشده
svn cp trunk tags/1.0.0

svn add --force trunk assets tags
svn ci -m "Ticketchi Lite 1.0.0" --username نام‌کاربری
```

بعد از چند دقیقه صفحه افزونه این‌جا فعال می‌شود: `https://wordpress.org/plugins/ticketchi-lite/`

### انتشار نسخه بعدی
1. `Version` را در `ticketchi-lite.php` و `Stable tag` را در `readme.txt` بالا ببر.
2. فایل‌ها را در `trunk` جایگزین کن.
3. دستور `svn cp trunk tags/1.0.1` و بعد `svn ci` را بزن.

## بخش ۵ — نکات بیزنسی

1. **قوانین راست‌چین را چک کن:** از پشتیبانی راست‌چین بپرس انتشار نسخه رایگانِ محدود (Lite) از محصولی که آنجا می‌فروشی مجاز است یا نه. این مورد را با اطمینان نمی‌دانم.
2. **لینک دوطرفه بساز:**
   - در صفحه محصول راست‌چین بنویس «نسخه رایگان را از مخزن وردپرس امتحان کنید» و لینک بده.
   - در صفحه وردپرس هم لینک پرو از قبل در readme هست.
3. **نظرات ۵ ستاره:** از چند مشتری راضی بخواه در wordpress.org نظر بدهند. رتبه افزونه در جستجوی «تیکت» خیلی به تعداد نصب و نظرها وابسته است.
4. **برچسب‌ها (Tags):** فقط ۵ برچسب اول نمایش داده می‌شود و الان انتخاب شده‌اند.

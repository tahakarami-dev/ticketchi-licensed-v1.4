A modern, right-to-left (Persian) support ticket system for WordPress and WooCommerce: customer panel, support inbox, departments, attachments and email notifications.

== Description ==

**Ticketchi Lite** turns your WordPress site into a clean, fast helpdesk built for Persian (RTL) websites and online stores.

Customers open and follow up their tickets from a beautiful panel – on any page with the `[ticketchi]` shortcode, or inside WooCommerce «My account». Your team answers everything from a full-screen, modern support inbox.

= Customer panel =

* Open tickets with department / sub-department, title, priority and description
* Attach a file to every message (size and extensions are configurable)
* Conversation view, reply, close the ticket when the problem is solved
* Status overview and filters (status, priority, sort)
* Works with the `[ticketchi]` shortcode and with WooCommerce «My account › Support tickets»
* Mobile friendly, Vazirmatn font bundled locally, Solar Hijri (Jalali) dates

= Support inbox =

* Full-screen app with views: open, waiting for customer, closed, all, trash
* Instant search by title, text, ticket number, customer name or email
* Reply with an attachment, «reply and close», change status, priority and department
* Dark mode

= More =

* Departments with sub-departments and descriptions
* Branded, RTL HTML emails for new tickets and replies (customer and support)
* Brand colours applied to the customer panel, inbox and emails
* No external requests: no Gravatar, no CDN, no tracking

== Installation ==

1. Install and activate the plugin from «Plugins › Add New», or upload the `ticketchi-lite` folder to `/wp-content/plugins/`.
2. Open «Ticketchi › Departments» and create at least one department.
3. Add the `[ticketchi]` shortcode to a page. On WooCommerce stores the panel is also available in «My account › Support tickets».
4. Adjust colours, attachments and emails in «Ticketchi › Settings».

== Frequently Asked Questions ==

= Who can answer tickets? =

Site administrators and WooCommerce shop managers. Support agents with their own role and per-department access are part of Ticketchi Pro.

= Is WooCommerce required? =

No. Without WooCommerce use the `[ticketchi]` shortcode on any page.

= What happens to my tickets if I upgrade to Ticketchi Pro? =

Everything is kept: tickets, replies, departments and settings. Activate Pro, then deactivate and delete Ticketchi Lite.

= Are my tickets deleted when I delete the plugin? =

No. Tickets stay in the database so nothing is lost when switching to Ticketchi Pro or reinstalling.

= Where are attachments stored? =

In `wp-content/uploads/tkm-uploads/YEAR/MONTH`. WordPress' own allowed file types always apply on top of the extensions you allow in the settings.
